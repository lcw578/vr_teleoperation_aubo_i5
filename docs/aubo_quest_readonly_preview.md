## 启动和现场验收

先退出其他仿真/遥操和单独 relay，以免占用会话锁或 8443。不要同时运行旧业务的运动服务。新入口自动启动原 HTTPS relay，无需另开 `run_relay.sh`。

```bash
cd /home/lcw/VR_teleoperation
bash scripts/aubo_quest_preview.sh --connect \
  --host 192.168.1.5 --port 8899 --user aubo
```

按提示输入 SDK 密码，密码不进入参数、状态页或录制。复用当前 SDK 构建，无须安装新库。退出用 Ctrl+C 或关闭 MuJoCo 窗口；先停止接收和查询任务，再退出 SDK，不自动归位。

2026-10-19 本轮查看到电脑 Wi-Fi/热点 IP 为 `10.42.68.27`，机器人网卡 IP 为 `192.168.1.100`。头显浏览器访问：

```text
https://10.42.68.27:8443/
```

按原流程接受自签证书，进入 Teleop 和腕部校准。若换热点/DHCP 变化，用 `ip -4 -brief address` 查同网段 Wi-Fi 地址，不使用机器人 `192.168.1.5` 打开网页。电脑状态页为 `https://127.0.0.1:8443/aubo`，JSON 为 `/aubo/status`。

操作顺序：

1. 实体机械臂保持静止。桌面实体橙灰模型显示实际反馈，青色半透明模型是未发送候选；重合时青色可能不明显。
2. 先松开 Grip，再按 Grip。启动时已按住不会直接接合。缓慢平移/转动手柄，观察候选变化；当前默认已取消额外的 0.5°/s、5°/s 预览限速，速度边界、IK 步长及 200 Hz 周期复用已验收仿真基线。若需主动降速可追加 `--preview-speed-deg-s 5`；这只影响候选，不改变实体限速。
3. 检查工作区平移、拧钥匙和点头摆动。当前无夹爪，以法兰轴观察；头显转动不参与方向映射。默认 `world`，可另启 `--rotation tool_local` 比较。
4. 松 Grip，候选撤销。重新摆手柄再按，必须从当前实际关节 FK 建锚，不沿上次未执行目标继续。
5. 暂停 XR 输入，检查故障和 `require_release`。恢复时保持 Grip 不自动接合；有有效反馈和输入后，须松开再按。WebSocket 重连和参考空间变化同样需要重新释放。

Trigger 没有实体动作，网页参数滑条暂不生效，摇杆归位屏蔽。没有相机或实体夹爪接入，不修改 TCP、负载或仿真姿态。

如果按 Grip 看不到青色候选，在电脑打开 `/aubo` 检查 `xr_input`：`right_present` 表示本帧是否有右手位姿，`grip` 表示右手柄按钮 1 是否按下，`valid_frame_age_s` 表示最近有效帧的主机年龄。`last_error` 保留最近一次拒绝原因，不表示当前仍然故障；结合 `engaged`、`fault`、`require_release` 判断。`relay_connected` 仅代表电脑已连接 Relay，不能据此认为头显手柄已正常输入。`candidate_max_delta_deg` 是候选与实测关节的最大差值；实体色模型应持续反映静止真机，不随手柄移动。

可选 `--headless` 隐藏桌面，`--duration 10` 限时运行；`--usb` 对应既有 adb reverse 和 `http://localhost:8443/`。默认命令仅打印计划，不加载 SDK：

```bash
bash scripts/aubo_quest_preview.sh
```

## 链路和边界

```text
原 WebXR 腕部校准/右手柄 → 原 Relay /ws → 输入接收任务
  → 既有候选协调器/唯一控制主循环 → 原作者滤波、离合、目标管理、解耦 IK
  → 未发送关节候选 → 青色桌面预览和状态页

控制柜 → 原只读绑定/Get 查询任务 → 有效反馈缓存
  → 实际状态建锚、实体色桌面显示
```

仅加载 `_aubo_readonly`，不加载 J6 运动实验扩展。该绑定不导出运动、stop、startup 或清错 API；入口也没有 `--execute` 或网页开启运动的开关。它不能替其他程序停止机器人。

复用 `OfflineRuntime` 的 candidate-only 选项，不调用假发送，不合成反馈。原 fake-only 会话对象只管理本地候选与恢复门控；`local_revoke_requests` 是本地演练计数，不是已向柜子发 stop。此处验证候选撤销与恢复，不等于真机 Grip 停止已经验收。

网络线程逐帧验证输入，只缓存最新运动帧，并保留短暂 Grip 释放、追踪失效、参考空间改变与断连事件。主循环才修改核心和求解；这些事件不能被后来的正常帧隐藏。故障帧之前缓存的释放不能用作恢复释放。

反馈任务串行查询“关节+停止状态”，主机期望周期 50 ms、总查询预算 200 ms；失败或柜子不再报告停止就撤销候选并结束查询任务，不自动重连。主循环不被查询直接阻塞，但本阶段不是硬件停止架构。

当前预览计算 200 Hz，默认速度边界与 IK 步长复用已验收仿真入口；输入和反馈主机年龄上限 250 ms、候选年龄上限 100 ms。计算频率不是硬件发送频率，仿真速度参数也不是已验证的实体配置。Logger 默认关闭，不持续写关节或图像；本轮有限联调资料在 `/data`。

## 法兰适配与算法复用

法兰模型从 `scene_aubo_i5_rg.xml` 的机械臂部分复用，仅在内存中删除 RG 子树并增加 `tool0`、`j4_anchor`。编译结果为六关节、零执行器、零相机；`tool0` 与 `wrist3_Link` 重合。保留作者腕部枢轴、滤波、离合和解耦 IK，不复制另一套控制算法，不改原场景文件、RG_READY、相机或原仿真入口。

初始状态和作者 rest bias 都取本轮最初的有效实测关节，避免偏置指向仿真 RG_READY；偏置数学公式不变。预览不自动回到初始姿态。

位姿采用原模型基座坐标。SDK 基座 Z 差 −23.5 mm 的数学对应另见[法兰对照](aubo_flange_and_follow_review_2026-10-19.md)，没有把它加到关节角或将模型当现场碰撞地图。现场法兰支架与线缆尚未建模，不能从无夹爪模型推断其碰撞余量。

## 目标与当前共识

目标是在完成采摘并确认番茄串已分离、夹持稳固后，按一次左 X，按可预测的分段路线把番茄串运送至蓝色收集框并释放。

当前认可的动作骨架：

```text
采摘完成并确认夹持
  → 保持适合携带番茄串的夹持姿态退出植株
  → 返回初始中转位置
  → 在空旷区域转向并调整到放置姿态
  → 移至蓝框上方/释放位置
  → 到位停稳后释放
  → 确认释放完成
```

将“先移动大臂到空旷区域，再调整手腕”作为**待实测的分段动作策略**。它表达的是先让负载离开植株附近，再整理末端姿态；并不预先规定运动中只能动前三轴、后三轴必须完全静止。必要时六轴可协调运动，以保持夹爪/番茄串的姿态和路径。

本功能先分成两个可独立验收的交付：

- **P1 空载到位**：左 X 触发后，从指定中转起点经固定过渡点到蓝框上方，确认停稳；不操作夹爪。
- **P2 带果放置**：具备夹持确认后，按验证过的退出和转运路径运送，并在停稳确认后释放和检查结果。

P1 成功不代表已实现自动采摘、自动判断剪切成功或完整带果放置。

## 方案评估与边界

把初始位置用作固定中转位，可以把变化较大的采摘区路径和相对固定的蓝框路线分开，便于示教、复现和排查。徐灿源码中的返回动作也使用保存的中间路点并最终到达固定位置，说明固定路点分段与当前系统兼容；但其流程依赖前一次采摘生成的上下文，不能直接等同于我们从任意遥操起点返回。

当前左 Y 回位按六轴关节参考朝保存的 home 运动，并不是对刚才遥操进入路径的反向重放。不能先假定“按现有左 Y 回初始位”就一定能安全带果退出植株。需要单独确认：初始位是否留有果串净空、适合转向且能安全停留；若不适合，应示教专门的“带果中转位”，而不是强行复用旧 home。

关节角与末端姿态相关。前三轴转动时，腕关节数值保持不变并不保证夹爪朝向不变；只动后三轴也可能令长夹爪或果串扫过空间。因此每一段要按工具/负载实际扫掠体检查。点到点 JointMove 会在关节空间运动，不保证工具端直线，也不会自动感知植株、蓝框、车体或线缆。

## 动作策略的实验安排

“大臂先到空旷区域、随后调整手腕”要比较的是动作结果，而不是死板锁定关节组：

1. 空载、远离作物时记录当前六轴角与末端姿态，分别小幅改变大臂关节和手腕关节，观察夹具相对基座的方向和位置变化，核对模型映射。
2. 在不带果、无障碍的前提下演练候选中转位；比较协调运动与“先主体搬运、后腕部调整”在路径净空、末端扫掠和总耗时上的差别。
3. 初始只验证固定路段和小范围；把“腕部调整”放在确认空旷的位置。记录起点、每个目标、实测反馈、停止/取消、工具朝向和人工观察结果。
4. 仅在空载路线稳定后带入模拟负载或实际夹持物。先验证退出段与中转位净空，再连完整转运；不直接第一次就带果跑全路径。

若先动大臂会使果串扫向植株/车体，或改变夹持朝向，则允许腕部在退出段同步补偿；这不违背“先搬到空旷区域再调整放置姿态”的总体顺序。决策依据是工具和负载的实际扫掠，而非单独看哪些关节在动。

## 软件实现约束

- 只有一个运动 owner；不得让当前遥操进程和徐灿 ROS 节点同时给机器人发送运动命令。
- 首版可由操作者人工确认果柄已分离、夹持稳固后，再按左 X 请求搬运；文档和界面必须明确这是人工确认，不能把按键当作传感器证据。若需要防误触的独立确认，现场确定后再加入，不预先叠加多次操作。
- 自动动作的状态观测、分段事件和录制不依赖继续按住右 Grip，避免重现“未接合遥操就无法记录自动流程”的问题。原始观测可以保留，是否进入训练样本另行决定。
- 自动动作遇头显/控制输入失联时，建议按明确输入时效停止并取消剩余路径，重连不自动续跑。具体输入源与阈值在编码前确认，避免把姿态短暂不可用与真正会话失联混为一谈；不得因 oneshot 语义忽略失联。
- 新动作默认从允许起点集合启动；状态故障/未知、反馈不新鲜、运动未停稳、工具配置不匹配时拒绝启动。
- 点到点接口的“非阻塞”只表示不等到位，不承诺 SDK 网络调用一定短；实现前要确认 owner 仍能处理取消和状态检查。
- 每一段之间检查新的关节/状态反馈；失败或超时进入明确停止/未知状态，不跳过失败段继续去蓝框。
- 左 Y 和左 X 互斥；取消后不能续发旧路点。自动动作到位由反馈确认，不能把 SDK 返回成功当作实体到位。
- 录制保留 placement 阶段、命令来源和观察；柜端点到点运动不能伪装成 25 fps 逐点遥操 action。
- 首个版本不让网络 ACK 实验、200 Hz 改频、相机链路变化和夹爪释放一起进入，减少变量。

## 推荐推进顺序

初步重复次数建议：已检查的空载固定路段每段至少 3 次；完整 P1 空载循环至少 5 次，并另验取消和重新接管；再用尺寸接近实际、固定可靠的模拟夹持物验证退出与净空，最后做少量真实带果试验。次数是本轮工程验收安排，不代表可靠性认证；出现异常就先取证、修正，再重验受影响项目。速度、退出距离、释放高度和果串包络均现场确定，当前不填写未经测量的数值。

当前可先做的离线工作：整理当前 home 配置与参考、将徐灿代码的关节路点和调用顺序逐项对照、完成左 X 按键语义/状态机草案、确定所需录制事件。它们不需要启动机器人，也不依赖猜测现场坐标。

现场和徐灿信息到齐后，先生成候选路点配置和净空检查，再按 **固定空载路线 → 左 X P1 → 退出段 → 带果搬运 → 夹爪释放 P2** 逐阶段验收。左 Y 已通过本次停止/归位现场验证，作为现有基线继续观察；延迟诊断另开工作包，不混入这条路线。

每项现场实验开始前明确当前姿态、预期路径和停止处置；每次只新增一个路径段或一种控制行为。若实际姿态/障碍物与计划不符，停止该阶段并重新示教，不通过按键反复重试来探索路径。

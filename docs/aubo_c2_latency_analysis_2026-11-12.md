# C-2 持续跟随延迟分析（2026-11-12）

> 当前版本已由用户确认为[真机基线 aubo-c2-refined90-2026-11-12](aubo_teleop_baseline_2026-11-12.md)。本文保留该轮实验/诊断的原始时序与状态；“待验收”“当前未启动”等措辞属于当时记录，不覆盖后续基线结论。

用户反馈：25/75/600遥操可用，但持续捏住Grip移动时机械臂需要时间追到指定位置。本次只读分析，没有改变运动参数、阈值或执行程序运动，也没有将“感觉可以但仍有延迟”扩大为C-2延迟问题已通过验收。

数据来自车端 c2-practical-20261112/C2-20261112-185343/diagnostics.jsonl。提取时约245MB，完整原始记录留在车端，本机只存选取的参考、目标、反馈和计时数据（压缩约10.8MB），路径 /data/VR_teleoperation_runtime/c2-practical-20261112/C2-20261112-185343/。latency-analysis.json为统计，latency-layers.png为代表片段。记录中已有1次冷预热、38次热接合、39次释放、1次运动零速恢复，无硬闭锁；读取时处于idle，已确认停止。进程仍保留原1800秒寿命，没有另启动运动。

## 分层结果

15806个ACTIVE批次的统计（以每条记录六轴绝对差的最大值为指标）：

| 指标 | 中位数 | P95 | 最大值 |
| --- | ---: | ---: | ---: |
| 最新IK目标−生成参考 | 3.455° | 28.515° | 48.952° |
| 生成参考−当帧已测关节 | 0.843° | 2.317° | 3.881° |
| A发送RPC | 8.929ms | 24.756ms | 86.878ms |
| A发送开始时C回调样本年龄 | 13.176ms | 24.622ms | 55.913ms |

这不是同时刻的物理跟随误差认证；第二项包含已提前排入的参考、反馈传输年龄。持续跟随时有大量位置差已经在生成发送点之前形成，主机参考追目标是主要优化对象。仅18个ACTIVE批次出现target_replan_deferred，并不存在普遍被旧不可行曲线拒绝改目标的证据。

有目标误差>1°的批次，参考最大轴速度中位8.353°/s、P95=17.028°/s；全轮最高21.047°/s，没有达到24°/s的批次。将IK目标按同一接合内250ms平均差分，最大轴需求速度P95=34.402°/s，约9.61%样本超过25°/s。后一项说明快动作有真实速度上限造成的自然追赶时间，不能将全部位置差都解释成可消除的固定通信时延。

运动窗口每秒一次control_loop_timing.last样本的runtime_step中位0.448ms、P95=1.386ms；完整会话在线累计最大runtime_step约21.1ms，记录的100ms控制循环stall计数为0。该数据不是逐帧IK执行时间全量分布。Grip接合延迟中位2.437ms、最大4.940ms，属于接收输入到模式切换，不是端到端动作延迟。

## 规划器的额外保守性

teleop/aubo/trajectory.py 的_plan每次从当前q/v/a规划至目标，末端v=a=0；用Bezier导数控制点凸包作为整段导数的充分约束，时长按1.2倍搜索。它保证上界，但并非时间最优，也不意味着实际速度能接近配置上限。

以静止起步、单轴固定目标的25/75/600配置离线复现：

| 目标位移 | 现有规划时长 | 实际曲线峰速 |
| --- | ---: | ---: |
| 1° | 0.666s | 2.817°/s |
| 5° | 1.380s | 6.793°/s |
| 10° | 2.385s | 7.862°/s |
| 20° | 4.121s | 9.099°/s |

这是从源码计算的固定目标示例，不是本轮所有动作的测得到达时间。静止起步的控制点为(q,q,q,goal,goal,goal)，速度导数控制点中间项为5Δq/T；凸包约束要求5Δq/T≤vmax，而这条曲线真实峰值只有1.875Δq/T，速度约束因此保守。还有加速度/jerk约束、同时六轴取共同可行时长，以及不断更新的目标要考虑。移除这些约束或直接置位置会破坏当前平顺与制动边界，不属于本次分析操作。

受控自检用ProgramSineTrajectory预生成约24°/s正弦，VR使用上述在线目标追踪；前者证明供点和制动能力，不证明后者已充分使用25°/s上限。

## 参考到实测的附加滞后

从原始回调时间戳去重，选择参考速度>3°/s的5811个样本，将发送批末参考曲线整体平移0～300ms做六轴最小二乘拟合，最佳平移119ms、RMS约0.137°。这是本轮整体相关拟合，包含名义80ms前瞻、柜端执行和反馈传输；没有把它分拆为已认证的各段时间，也不是同步测量的手部输入到电机时延。不能把RPC中位数再简单与119ms相加。

原始日志没有连续保存全部原始手部/TCP目标，也没有头显与主机时钟同步，不能精确测出总手到机械臂延迟；作者默认pose_filter_alpha=0.8，不能据默认值断言本轮网页设置未变。现有证据优先支持优化新增在线轨迹层的追赶效率，再权衡缩小缓冲垫；直接升级35档或仅调通信无法独立消除目前规划器的保守性。应保持q/v/a连续和真实v/a/j边界，比较同样动作下的目标−参考差与尾段收敛时间。
